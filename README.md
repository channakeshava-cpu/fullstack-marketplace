# Full-Stack E-Commerce Marketplace

A full-stack e-commerce marketplace built to develop practical skills in backend engineering, frontend development, database design, and scalable application architecture.

## Technology Stack

### Backend
- Java 21
- Spring Boot
- Spring Data / database integration
- Maven

### Frontend
- React
- Vite
- JavaScript

### Database
- PostgreSQL
- Flyway database migrations

### Tools
- Git and GitHub
- IntelliJ IDEA
- npm

## Project Structure

```text
ecommerce-backend/
├── backend/    # Spring Boot application
├── frontend/   # React application
├── docs/       # Technical documentation
├── .gitignore
└── README.md
```

## Running Locally

### Backend

Configure the required database environment variables, then start the Spring Boot application from the `backend` directory.

### Frontend

From the `frontend` directory, run:

```bash
npm install
npm run dev
```

The frontend development server normally runs at `http://localhost:5173`.

## Development Approach

The project is developed incrementally, with an emphasis on maintainable code, secure APIs, database integrity, automated testing, and production-ready engineering practices.
